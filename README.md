# tlm_beyond_space-forge

车万女仆（Touhou Little Maid）的附属模组：超时空救援。

当前版本：`1.0.2`

- Minecraft 1.20.1
- Forge 47.x
- Touhou Little Maid 1.5.3
- 可选兼容：女仆史诗战斗、Maid Useful Task、Promaid

## 下载

将仓库根目录中的：

`[车万女仆_超时空救援]tlm_beyond_space-forge-1.0.2.jar`

放入对应整合包的 `mods` 文件夹。

## 主要功能

### 战斗女仆书

- 右键空气：打开非战斗工作模式的救援配置。
- 右键自己的女仆：用书中整套配置覆盖该女仆。
- Shift + 右键：将主人名下所有女仆的非战斗救援选项重置为“禁止”。
- 金色提示语：`这就是我们的羁绊！`

每个非战斗工作模式可以设置：

- 禁止：该工作模式下不自动参与救援。
- 独行模式：主要在女仆自己遇到危险时战斗。
- 羁绊模式：女仆也会响应主人遇袭或主人附近的威胁。

### 女仆配置页

女仆界面顶部增加“超时空救援”配置页：

- 第一行独立选择该女仆的救援战斗模式。
- 下方分页设置每个非战斗工作模式的救援选项。
- 左三角切换前一项；中间或右三角切换下一项。
- 页面修改只作用于当前女仆；再次用战斗女仆书右键会用书中模板覆盖。

### 救援信号

- 普通右键：向名录中允许响应的女仆发出求救。
- Shift + 右键：打开女仆名录。
- 支持已加载女仆的跨维度救援与返程。
- 可从界面遣返正在救援的女仆。

### 女仆的武器匣

- 在物品栏中右键物品，将一件武器收入武器匣。
- 右键空槽取出武器。
- 救援战斗开始时，若武器符合当前攻击任务要求，会自动装备。
- 战斗结束后恢复原主手物品，并将救援武器放回武器匣。
- 包含女仆史诗战斗兼容处理。

## 从源码构建

需要 Java 17：

```powershell
.\gradlew.bat test jar
```

构建产物位于 `build/libs/`。
