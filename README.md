# tlm_beyond_space-forge
# TLM Beyond Space V7 玩家使用说明

> 适用于 Minecraft 1.20.1 / Forge 47.x / Touhou Little Maid 1.5.3。  
必要前置：车万女仆(Touhou Little Maid)1.5.3

直接下载[车万女仆_超时空救援]tlm_beyond_space-forge-1.0.0.jar放置到MOD文件夹下就行。

## 1. 这个 Mod 能做什么？

它给东方女仆增加了一套“遇到危险临时切战斗、结束后回去继续干活”的救援系统。

你主要会用到三个物品：

- **战斗女仆书**：决定女仆什么时候帮忙，以及帮忙时切到什么攻击模式。
- **救援信号**：你主动求救，召集选中的女仆；已加载的女仆即使在其他维度也可以过来。
- **女仆的武器匣**：让女仆平时继续拿工作用品/普通武器，救援时临时换成专用战斗武器，结束后再放回去。

---

# 2. 战斗女仆书

## 怎么获得

用 TLM 祭坛合成：

- 木剑 ×1
- 书 ×1

## 怎么设置

拿着战斗女仆书，**右键空气**打开配置。

最上面有一个：

```text
攻击模式
```

这里选择女仆进入救援战斗时要切换到的攻击模式，例如原版近战、枪械攻击，或者其他战斗附属 Mod 添加的攻击模式。

下面每一种工作模式可以设置：

### 禁止

女仆处于这个工作模式时，不参加自动救援。

适合：

- 你不希望某个专职女仆突然离开工作岗位。
- 某个工作 Task 切换后容易中断重要流程。

### 独行模式

主要在**女仆自己遇到危险**时进入战斗。

适合：

- 希望女仆保护自己。
- 不希望主人每次打架都把她叫过来。

### 羁绊模式

女仆除了保护自己，也会关注主人受到攻击或主人附近出现威胁；必要时会来到主人附近参加战斗。

适合：

- 日常跟随/基地防卫。
- 希望主人遇袭时附近女仆自动支援。

## 怎么绑定给女仆

设置并保存以后：

- **右键自己的女仆**：把这本书的当前配置绑定给她。
- **潜行右键女仆**：解除这一只女仆的绑定。
- **潜行右键空气**：解除这本书记录的全部绑定。

### 很重要

如果你已经绑定过女仆，后来又修改了书里的“攻击模式”或救援方式，**请再右键绑定一次女仆**，让她拿到新的配置。

# 3. 救援信号

## 怎么获得

TLM 祭坛：

- 战斗女仆书 ×1
- 末影珍珠 ×1

## 第一次使用前先设置名录

拿着救援信号，**潜行右键**打开女仆名录。

每只女仆会显示类似：

```text
同维度 · 已加载
其他维度 · 已加载（可召集）
未加载（当前不召集）
```

然后选择：

```text
求救：是
求救：否
```

设置成“否”的女仆完全不会响应，而且不会在使用信号时刷失败提示。

## 怎么求救

普通右键救援信号。

系统会尝试召集名录中允许响应的女仆。

### 跨维度

如果女仆：

- 在主世界，你在地狱；
- 或者她在地狱，你在主世界；
- 或者其他可加载维度之间；

只要**那只女仆当前实体是已加载状态**，她就可以跨维度来到你身边。

救援结束后，她会尝试回到出发维度，并回到原位置附近的安全位置。

### 未加载女仆

当前版本不会强制加载远处、已经卸载的女仆。

所以名录显示：

```text
未加载（当前不召集）
```

时，这次信号不会把她硬拉出来。

## 救援信号用什么攻击模式？

V7 不再给救援信号单独设置攻击模式。

它直接使用**这只女仆绑定的战斗女仆书里的统一攻击模式**。

也就是说，你只需要在战斗女仆书里设置一次，不必再在救援信号里重复配置。

如果配置的攻击模式因为你卸载了对应 Mod 而不存在，系统会尝试回退到 TLM 原生“攻击”模式。

# 4. 女仆的武器匣

## 怎么获得

TLM 祭坛：

- 箱子 ×1
- 粉色染料 ×1
- 铜锭 ×4

## 怎么放武器

在物品栏中使用武器匣和物品进行右键交互，可以把一件物品收进去；对空槽操作可以把里面的物品拿出来。

鼠标放在武器匣上会显示：

```text
内部：空
```

或者：

```text
内部：某件武器
```

然后把武器匣装备到女仆的饰品栏。

## 救援时怎么工作

假设：

```text
女仆平时主手：工作用的剑 A
武器匣：枪 G
战斗女仆书攻击模式：枪械模式
```

救援触发时，Mod 会先问这个“枪械攻击模式”：

> 枪 G 是不是你认可的武器？

如果该攻击模式认可：

```text
枪 G → 主手
剑 A → 武器匣
```

然后女仆切到枪械模式战斗。

战斗结束后：

```text
战斗后的枪 G → 武器匣
剑 A → 主手
```

枪在战斗中掉的耐久不会被回档。

## 如果攻击模式不认可武器匣里的东西

例如：

```text
攻击模式：近战
武器匣：枪
```

V7 不会强行把枪拿出来。

武器匣保持原样，近战 Task 自己决定从主手或背包使用什么武器。

这样可以避免以前那种：

```text
枪被拿到主手
→ 近战模式不认枪
→ 又从背包拿一把剑
→ 枪被塞进背包
```

的问题。

## 如果战斗 Mod 又自动换了武器呢？

V7 会给自动取出的武器加临时追踪标记。

如果第三方攻击 Task 在战斗中把这把武器从主手挪到了女仆背包，结束时 Mod 仍会在背包中寻找它并恢复回武器匣。

因此比旧版更不容易出现“武器匣里的枪莫名其妙留在背包”的情况。

# 5. 推荐配置方法

## 枪械女仆

1. 战斗女仆书顶部选对应的枪械攻击模式。
2. 常用工作 Task 设成“羁绊模式”或“独行模式”。
3. 保存。
4. 重新右键绑定女仆。
5. 给女仆装备武器匣。
6. 武器匣里放该枪械模式认可的枪。
7. 救援信号名录把她设为“求救：是”。

这样普通自动救援和跨维度救援信号都会使用同一枪械模式。

## 近战女仆

- 战斗书攻击模式选原版“攻击”或其他近战攻击 Task。
- 武器匣放该 Task 认可的近战武器。
- 其余配置同上。

## 不希望离岗的生产女仆

如果某个工作模式不能被中断：

```text
该工作模式 → 禁止
```

她在这个 Task 下就不会因为普通自动救援突然切走。

救援信号是玩家主动求救，是否响应则由救援信号名录的“求救：是/否”决定。

# 6. 哪些情况下不会响应？

救援信号可能因为这些原因跳过某只 Maid：

- 当前未加载。
- 已经不属于你。
- 正在执行其他救援 Session。
- 战斗攻击模式已经失效。
- Task 切换失败。
- 你身边没有找到安全落脚点。
- 跨维度迁移失败。
- 目标世界创建/验证 Maid 失败。
- 源世界旧实体没有正确完成迁移清理。

系统会尽量把 Maid 名称和原因一起汇总显示。

但如果你手动设成：

```text
求救：否
```

则是安静跳过，不会当成错误。

---

# 7. 跨维度救援的适用范围

适合：

- 你在地狱探险，基地里的已加载战斗女仆来支援。
- 你从主世界进入末地，希望已经加载的指定 Maid 临时参战。
- 多只不同工作岗位 Maid 在需要时临时切战斗，然后返回原岗位附近。

不适合/当前不做：

- 强制加载很远、已经卸载的 Maid。
- 把普通“羁绊模式”变成任意跨维度追主人功能。
- 救援结束后把 Maid 的所有状态回滚到战斗前。

---

# 8. 救援期间哪些东西会保留？

会保留真实游戏变化：

- 捡到的新物品。
- 已经消耗的物品。
- 武器和装备的耐久变化。
- 血量变化。
- 其他正常实体状态变化。

系统只恢复救援临时改变的部分，例如：

- 原工作 Task。
- HomeMode。
- Schedule。
- 武器匣自动换装关系。
- Rescue Session 状态。

所以它更像“把女仆临时派出去战斗再送回去”，不是“读档”。

---

# 9. 使用时的几个注意事项

1. **修改战斗女仆书后记得重新绑定 Maid。** 绑定时是把当前配置复制给 Maid。
2. **救援信号只能召集已加载 Maid。** 名录里会直接显示加载状态。
3. **攻击模式和武器匣武器要匹配。** 判断由攻击 Task 自己完成。
4. **第三方攻击模式最好规范实现 TLM 的 `IAttackTask`。** 这样兼容最自然。
5. **跨维度测试时尽量不要在曾经出现重复 UUID Maid 的旧测试存档继续测试。** 当前 V7 已修复该问题，但早期实验版可能在世界里留下异常实体。
6. 如果一次跨维度失败，优先看聊天中的具体跳过原因；严重的部分迁移问题还会写入日志。

---

# 10. 最短上手流程

```text
1. 祭坛做战斗女仆书
2. 右键空气，选统一攻击模式
3. 给常用工作 Task 选择 禁止 / 独行 / 羁绊
4. 保存
5. 右键自己的 Maid 绑定
6. 做女仆的武器匣，放入与攻击模式匹配的武器并装备给 Maid
7. 做救援信号
8. 潜行右键信号，把需要的 Maid 设为“求救：是”
9. 普通右键信号求救
```

如果你只想要自动保护而不需要主动跨维度召集，前 1～6 步就足够。
